# Project requirements

This repository is a Homey SDK v3 TypeScript app, not an Android app. Preserve its architecture and existing local appliance protocol.

Washer statistics: persistent per-device cycle tracking; completed, aborted and unverified results; lifetime/monthly aggregates; latest 500 cycle records; device counters and Flow tokens; localized settings dashboard. Statistics start when tracking is installed and cannot recover prior program history. Never treat forecast percentages as measured consumption.
